# Python Projects

A collection of Python projects demonstrating programming fundamentals, 
data analysis, web scraping, and automation. These projects showcase 
my practical application of Python to solve problems, extract 
information, analyse datasets, and automate everyday tasks.

## Projects

### 1. Exploratory Data Analysis & Data Visualisation

**Overview:**  
An exploratory data analysis project using Python and Pandas to 
investigate a world population dataset, identify patterns, and 
extract meaningful insights. The project applies data manipulation, 
grouping, aggregation, and visualisation techniques to explore 
population trends and comparisons across countries and continents.

**Technologies:** Python, Pandas, Matplotlib and other libraries used 
in the analysis.

**Key Skills:** Data cleaning, exploratory data analysis, statistical 
summaries, data manipulation, and data visualisation.

### 2. Amazon Product Web Scraper & Price Tracker

**Overview:**  
A Python-based web scraping project designed to extract product 
information, including titles and prices, from Amazon product pages. 
Using Requests and BeautifulSoup, the project retrieves and parses 
HTML content, extracts relevant product details, and stores the 
collected information in a CSV file. It also explores automated 
price monitoring by recording product prices alongside collection 
dates for historical tracking.

**Technologies:** Python, Requests, BeautifulSoup, CSV.

**Key Skills:** Web scraping, HTTP requests, HTML parsing, data 
extraction, file handling, and automation.

### 3. Automated File Sorter

**Overview:**  
A Python automation project that organises files into appropriate 
folders based on their file types. It demonstrates how Python can 
simplify repetitive file management tasks, improve organisation, 
and reduce manual effort.

**Technologies:** Python, OS and file-handling libraries used.

**Key Skills:** Automation, file management, conditional logic, 
and working with directories.

### 4. BMI Calculator

**Overview:**  
A beginner-friendly Python application that calculates Body Mass 
Index (BMI) using a user's height and weight. The project applies 
fundamental programming concepts to accept user input, perform 
calculations, and present the resulting value.

**Technologies:** Python.

**Key Skills:** Variables, user input, arithmetic operations, 
conditional logic, and output formatting.
